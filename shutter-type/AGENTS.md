# Shutter Type — an unbland effect

Letters arrive from under their own clipped edge, with the reveal sweeping across the block as one front.

This folder is a free unbland effect, not part of the host project's source.

**Read `SKILL.md` before doing anything with it.** It carries the installation
steps for each supported format, every configuration option, what must not be
edited, how to remove the effect cleanly, and the compatibility limits.

`unbland.json` lists the files that ship and which one serves which install
path. `dist/demo.html`, where present, is a working page to check against.

Version 1.0.0. Do not modify the effect's own source to configure
it — use the documented options.
